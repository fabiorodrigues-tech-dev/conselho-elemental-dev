# 🧙‍♂️ Domínio do Mago - Health & Fitness App

Uma aplicação web moderna focada no monitoramento de saúde, execução de treinos e análise de métricas corporais. Este projeto é desenvolvido de forma colaborativa, com foco em uma interface de alta fidelidade (Front-end) e lógica robusta de dados (Back-end).

## 🚀 Tecnologias Utilizadas
*   **Front-end:** React, Vite, Tailwind CSS, Zustand (Estado global) e Recharts (Visualização de dados).
*   **Back-end:** [Espaço para o seu amigo preencher com a stack que vai usar: Node.js, Java, Spring, etc].

## 📱 Módulos Principais

**1. Aba Treinos (Workout Flow)**
*   Seleção de categorias de exercícios.
*   Ecrã de execução ativa com temporizador e barra de progresso.
*   Resumo de desempenho pós-treino (calorias ativas, frequência cardíaca e duração).

**2. Aba Saúde (Health Dashboard)**
*   Anéis de progresso diário (Sono, Exercício e Água).
*   Mapeamento de estatísticas corporais e gráficos de tendência.
*   Resumo semanal e histórico completo de atividades.
